# Info Segugio 🔎

Info Segugio è un assistente che **fiuta le informazioni sul web** al posto tuo.

Scrivi l'argomento che vuoi approfondire e il segugio:

1. trasforma la tua domanda in una **query di ricerca ottimizzata**;
2. cerca sul web con **Tavily**;
3. crea un **riassunto** delle fonti trovate;
4. individua cosa manca e fa una **nuova ricerca di approfondimento** (fino a 3 ricerche);
5. ti consegna il **riassunto finale** con l'elenco delle fonti consultate.
